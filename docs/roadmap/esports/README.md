## 0) 重建总则(每片设计前对照)

1. **clean-room,不移植**:旧 Java / React-JS 代码只作业务逻辑参考——读它是为了理解领域语义(玩法规则、防作弊思路、配置运营机制),实现一律按新架构从零设计;每处设计先问「从零设计还会这么做吗」,不合理或不足直接丢弃,不背任何兼容包袱。目标是全新且更完善的产品,不是旧系统换语言。
2. **资产三级**:
   - **领域机制**(语义层,重新设计实现):Tier 分层重算+一致性闸门、评分三层架构、板块化自适应报告、匹配两层编排、配置驱动运行时(文案/时长/难度后台下发)、entitlement 事件模型、同龄百分位+置信分层;
   - **经验数据**(数值层,内容保留):red_dot 冻结锚点常量(作初始校准值,按校准计划用新数据重校)、13 款测试配置种子内容、题库内容、8 维权重矩阵数值、9 款电竞游戏目录;
   - **代码结构**(一律不移植):遥测协议按新契约重设计(nullable 语义显式、服务端可复现判定规则入协议)、游戏引擎统一新框架、报告板块插件化重写、52 页复制粘贴收敛为参数化单流程。
3. **底座消费边界**:身份/会话/租户/审计/文件/授权 = system 既有面,esports 只做业务域;跨服务读走 RPC;禁止在 esports 生长身份关注点。旧系统假限频/单行配置表/菜单表等技术债不在新库复活。
4. **命名二分(全局生效)**:`game` = 电竞游戏标题(用户偏好/类型投票数据源);`test` = 测试项(编排与评分对象,13 款)。admin 菜单用「测试项配置」。「渠道」拆三词:marketing_channel(营销渠道)/ tenant(租户)/ pay_channel(支付渠道)。
5. **对齐口径(设计侧审计后生效,直接作为实现依据)**:
   - 13 款名单 = 设计侧名单:multi_target 入、skill_prediction 出(存量作废);
   - multi_target = Tier A(按代码现实,非 METRIC_SPEC_BATCH 旧文);
   - 判定阈值(完美/良好等)服务端单源下发,客户端只渲染不判定;
   - skill_trajectory 类别 = 通用(跨类型);
   - 评分双轨:无上限分走线性链(原始成绩×单位分×难度系数),权威分/档位走分位,两套并存不互替;red_dot 校准分继续做权威分输入;
   - 档位 S/A/B/C = 百分位前 5/15/40%/其余,四色金绿蓝橙;
   - 8 维认知 key 以旧仓 REPORT_FRONTEND_SPEC §3 命名为唯一命名,完整权重矩阵在新版规格档单源落档(旧仓 Java/SQL/接口文档三源合一);
   - 解锁权益(永久)与报告数据时效(过期 = 不再重算,历史版本可看)两层拆分;
   - 聚合增值边界:历次曲线+PR 免费;跨类型对比/同龄趋势/训练处方随会员;
   - 重测:切换类型按目标类型重排、允许同款再现;进行中 session 锁死随落库,不受跨天 seed 影响;成绩 = 每次尝试追加不覆盖、展示取最高。

## 1) 架构定案(已裁,不再议)

- **双服务**:system(既有 IAM/文件/身份)+ esports(新建,业务域);一 PG 容器两逻辑库。
- **esports 双面**:Admin* 面(员工会话+grants,selector 走 ADMIN 链)/ C 端面(会员会话+归属强制,MEMBER 链);population 不互通;accessLadder 按每服务 server 包自装配范式接线。
- **身份模型**:C 端用户 = system 第二身份聚合(membership/population 机制已落地);玩家画像 = esports 聚合 keyed by member_id;微信登录 provider 住 system(code 交换必须在服务端);短信 = 阿里云 dysmsapi(密钥/签名/模板照旧配置)。**短信分层(2026-10-20 裁决)**:发送管道=platform capability(shared-go/capability 短信家族,双实现 dysmsapi+mock/log 供开发与 e2e),验证码登录=system 新 provider(与微信 provider 同层,消费该能力);触发=E6b 余面 SMS 骨架片。
- **租户模型**:default = 公版租户;专版(首家 HL)= 租户轴数据分区;admin 客户端暂载平台运营面。
- **前端两工程**:后台复用 admin client(新挂 esports 业务模块);前台新建 ctr client(TanStack Start,微信 WebView 单 cookie 会话模型)。
