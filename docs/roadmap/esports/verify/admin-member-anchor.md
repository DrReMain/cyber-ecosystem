## §四 M2-1 语义钉(走查必核)

1. **续费=从到期日无缝顺延 31 天,追加新行**(append-only 续订史)——非原地延长;与 entitlement 家族行(单行棘轮,e2e 既有断言)是两种形状,membership 按行存
2. **终止=本行状态置 expired**(只改状态不删行),立即失效;期内永久解锁保留
3. 状态四值=有效/即将到期(≤7 天,读时推导)/已过期(读时推导)/已终止(terminated)
4. 来源值集=manual/支付(order_no)/激活码(旧);筛选项照此
5. 统计三卡=剩余天数(至 X 自动过期)/累计会员期(含本期 N 期续订)/期内解锁·永久保留(过期不清解锁记录)
6. 掩码形=153****7568(中三段);开通 Modal 注记「敏感 · 入审计」
