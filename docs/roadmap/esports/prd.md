### P1.0 结论先行(推荐稿)

1. **付费粒度 = trial(单次测试会话)**:¥19.9 买的是「该次单次能力报告的完整内容」,永久有效;不买报告类型。
2. **权益模型 = 一个事件账本 + 范围化 scope**,不是两套判定:
   `entitlement_event(scope_kind, scope_ref, source, granted_at, expires_at?)`;
   `scope_kind ∈ {trial, report_type, tenant}`。判定只有一条:某个权益的 scope 是否覆盖目标报告。
3. **scope=report_type 只用于三种来源**:存量迁移、激活码、ToB/学校默认;不新开「按类型零售」的购买通道。
4. **会员 = 时间窗内的发放器**:期内产生的 trial 报告自动解锁且永久保留(R2/R3);聚合报告的访问随会员有效,到期回锁(R4)。
5. **职业报告不收费、不设 SKU**:职业差距数值包含在单次能力报告内;职业聚合页**默认开放**,后台可配置为会员权益(或关闭)。
6. **认知 8 维报告不收费、不设 SKU**:ToB 的 6 项测试足以覆盖 8 维,ToB 默认开放;ToC 仅在 FPS + MOBA 都完成时技术上可生成,**默认不开放**,后台可配置为 `open`(免费开放)或 `membership`(会员权益)。
7. **报告访问策略是后台配置项**:`open(免费开放) / membership(会员权益) / tenant(租户开放) / closed(不开放)`;职业与认知报告只走策略,不经过购买/权益发放。
8. **单次报告免费层**:全指标(雷达/综合分/各维分数/百分位)+ **全部 S/A/B/C 档位** + 最高分 1 项完整分析 + 最弱 1 项「维度名 + 同龄差距」钩子;付费解锁其余维度的分析/建议/职业差距/短板处方。档位免费,因为它是分享裂变素材。
9. 这样既拿到 A(trial 粒度)的复购结构,又不把激活码/迁移/ToB 硬翻译成 trial——所谓「双轨」只存在于发放来源,判定仍是一条规则。

**边界澄清(写进验收)**:
- 单次报告的「职业差距数值」和「该次短板建议」属于单次购买内容;「跨报告训练处方/职业趋势」属于会员聚合内容。旧仓 block3 与 README §0 的措辞差异按此口径收口。
- 会员期内只自动解锁**期内产生**的 trial;入会前已上锁的历史 trial 不追溯(沿用 R2 原文;若要追溯,需单独裁,涉及收入口径)。
- ToC 的 8 维报告保留「完成度判定」技术能力(两类齐可生成);默认不设入口,后台可按 `open` / `membership` 配置开放,不收费。
- 职业/认知报告**不设 SKU、不走支付**;访问只由报告访问策略决定。存量类型码仍按迁移保真发放。
- **档位徽章全免费**:它是完成页、分享卡与裂变素材的一部分,不构成付费价值;付费只卖解读、建议、差距与处方。
